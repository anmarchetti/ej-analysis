## Imports

The component imports several modules and types to function properly:

- `FC` from `react`: Used to type the functional component.
- `classNames` from `classnames`: Utility function for conditionally joining classNames together.
- `useStore` from `frontend/hooks/useStore`: Custom hook for accessing the MobX store.
- `TStores` from `frontend/store/IStores`: Type definition for the stores used in the application.
- `generateGenericValues` from `frontend/utils/tracking/tracking.utils`: Function to generate generic values for tracking purposes.
- `CTAThemeType, IFullWidthBannerFields` from `models/data/IFullWithBanner`: Types used to define the properties of the full width banner components.
- `EventTypes` from `models/enum/tracking/EventTypes`: Enum for different types of tracking events.
- `EventActions, EventCategories` from `models/enum/tracking/GenericEventParams`: Enums for event action types and categories used in tracking.
- `RouterLink` from `frontend/components/common/RouterLink`: Custom component for handling routing links.
- `styles` from `frontend/components/renderings/FullWidthBanner/FullWidthBanner.module.scss`: Module CSS for styling.

## Structure

The component `FullWidthBannerButton` is a functional component typed with `FC` and props `IFullWidthBannerButtonProps` which includes:

- `CTATheme`: Theme of the call-to-action (CTA) button, defined by the `CTAThemeType` enum.
- `fields`: Object containing all necessary fields for the banner, typed by `IFullWidthBannerFields`.

### Props Structure

`IFullWidthBannerButtonProps` includes:
- `CTATheme`: Determines the style of the CTA button.
- `fields`: Contains further details like `CTA` link and `TrackingTitle`.

## Logic

### Tracking Setup

The component uses the `useStore` hook to extract `trackEventWithParams` from the `trackingStore`, which is used for sending analytics data when the CTA button is clicked.

### Conditional Rendering

The button checks if the `href` and `text` properties of the `CTA` are present. If either is absent, the component returns `null`, effectively not rendering anything.

### Button Styling

The button's class is dynamically set based on the `CTATheme`:
- Uses general button styles unless it's a link (`btn` class).
- Applies outlined style if `CTATheme` is `Outlined` (`btn--outlined` class).
- Uses link-specific styles if `CTATheme` is `Url` (style from `styles.link`).

### Event Handling

The `onClick` function:
- Triggers an event using `trackEventWithParams`.
- Passes event type, action, category, label (from `TrackingTitle`), and an object generated by `generateGenericValues` function.

### Component Return

Returns a `RouterLink` component with:
- `dataId` set to 'full-width-banner-cta'.
- `link` object containing the URL and text.
- Conditional `className` based on `CTATheme`.
- An `onClick` handler that triggers the tracking event.
- Displays the CTA text within the link.

This setup ensures that the full width banner button is both functional and analytics-ready, with dynamic styling based on the provided theme.
