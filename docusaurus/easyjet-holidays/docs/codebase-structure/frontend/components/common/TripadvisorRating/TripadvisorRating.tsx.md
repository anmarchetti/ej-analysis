### Imports

The TripadvisorRating component imports several modules and assets:

- `FC` from `react`: This is the TypeScript type for a functional component.
- `classNames` from `classnames`: A utility to conditionally join class names together.
- `SvgTripAdvisor` from `frontend/components/icons-new/TripAdvisor`: A React component that renders the TripAdvisor SVG icon.
- Helper functions and constants (`HALF_OF_STAR`, `roundRating`, `STAR_IDS`) from `./TripadvisorRating.helpers`: These are specific utilities to handle rating logic.
- `styles` from `./TripadvisorRating.module.scss`: Module CSS for styling the TripadvisorRating component.

### Structure

The `TripadvisorRating` component is defined as a functional component using TypeScript. It accepts props of type `ITripadvisorRatingProps`, which include:

- `rating`: A number representing the TripAdvisor rating.
- `customClass`: An optional string for custom CSS classes.
- `hasIcon`: An optional boolean to determine if the TripAdvisor icon should be displayed.
- `showRatingValue`: An optional boolean to determine if the rating value should be displayed.

The component returns a JSX element structured as follows:

- A `div` element with a dynamic class name combining a default class and any custom class passed via props.
- Conditionally rendered `SvgTripAdvisor` component if `hasIcon` is true.
- A series of `span` elements representing stars, generated by mapping over `STAR_IDS`. Each star's appearance (full, half, or inactive) is determined by the rounded rating.
- Conditionally rendered `span` displaying the rating value if `showRatingValue` is true.

### Logic

1. **Rating Calculation**:
   - The `rating` prop is processed by the `roundRating` function to normalize it to the nearest half-star increment. This rounded rating determines how many full or half stars should be displayed.

2. **Star Rendering**:
   - The component iterates over `STAR_IDS`, an array representing each star. For each star, it checks if the rounded rating is sufficient for a full star (`isFullStart`) or just a half star (`isHalfStar`).
   - Each star is a `span` with dynamic classes based on whether it is a full star, half star, or inactive.

3. **Conditional Rendering**:
   - The TripAdvisor SVG icon is rendered only if `hasIcon` is true.
   - The numerical rating value is displayed next to the stars only if `showRatingValue` is true.

This component effectively encapsulates the logic for displaying a TripAdvisor rating in a visually consistent and customizable manner, allowing for optional inclusion of the brand icon and the exact rating value.
