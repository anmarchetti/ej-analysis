### Imports

The script imports two TypeScript interfaces from `'code/fonts.config'`:

- `IFontTypeConfig`: Likely defines the structure for font configuration settings.
- `IFontTypeUrls`: Probably specifies the URLs for different font file formats.

These interfaces are used to type-check the parameters and ensure consistent usage of font-related data throughout the functions.

### Structure

The code defines several functions and a utility to manage web fonts:

1. **`getFontSrc(urls: IFontTypeUrls): string`**
   - Constructs the `src` property for a CSS `@font-face` rule based on the provided font URLs.
   - Handles two font formats: WOFF2 and WOFF.

2. **`getFontFaceAtRule(family: string, urls: IFontTypeUrls, descriptors?: FontFaceDescriptors): string`**
   - Constructs a complete CSS `@font-face` rule as a string.
   - Includes the font family, source (from `getFontSrc`), and optional descriptors (like `font-display`, `font-weight`, and `font-style`).

3. **`loadFontPolyfill(font: IFontTypeConfig): void`**
   - A fallback method to inject the `@font-face` rule into the document's `<head>` as a `<style>` element if the CSS Font Loading API is not supported.

4. **`loadFont(font: IFontTypeConfig): Promise<void>`**
   - Tries to load a font using the CSS Font Loading API (`document.fonts`).
   - If the API is available and loading succeeds, it adds the font to the document.
   - If the API is not available or if an error occurs, it falls back to the polyfill method.

### Logic

- **Font Source Construction (`getFontSrc`):**
  - This function constructs the value for the `src` property in an `@font-face` rule.
  - It checks if URLs for WOFF2 and WOFF formats are provided and appends them conditionally, formatted correctly for CSS.

- **Font Face Rule Construction (`getFontFaceAtRule`):**
  - Generates a string that represents a complete `@font-face` rule.
  - It utilizes `getFontSrc` for the `src` part and conditionally adds font descriptors if they are provided.

- **Font Loading (`loadFont`):**
  - Attempts to use the modern CSS Font Loading API to asynchronously load the font.
  - On success, the font is registered with the document.
  - On failure or if the API isn't supported, it uses `loadFontPolyfill` to ensure the font is still loaded using older methods.

- **Polyfill Handling (`loadFontPolyfill`):**
  - As a fallback, this function creates a `<style>` element and sets its `innerHTML` to the CSS rules generated by `getFontFaceAtRule`.
  - It then appends this style element to the document's `<head>`, ensuring the font is available even in environments where the CSS Font Loading API is not supported.
