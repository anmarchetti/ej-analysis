# http-requests 🚀

This directory contains HTTP request samples, environment configurations, and request bodies used by NPT Team for for testing and developing.

## 🛠️Usage

### Visual Studio Code

- Install the [REST Client extension](https://marketplace.visualstudio.com/items?itemName=humao.rest-client)
- Open 'http-requests' directory as a project in Visual Studio Code. This allows vscode to recognize settings.json with the environment configuration
- Select the correct environment by clicking on the environment name in the bottom right corner of the editor
- Open a `.http` file and click "Send Request" above a request

### JetBrains IDEs (Rider, WebStorm, IntelliJ IDEA, etc.)

- JetBrains IDEs have built-in support for `.http` files
- Right-click on a request inside a `.http` file and select "Run" or use the "Run" icon above the request
- Select the correct environment by clicking on the environment name in the 'Run with:' dropdown at the top of the editor
